# 손목 축 회전 시험 (10/7 박진용)

## 1. 왜 했나
003_DESK_STAND 조립(10/7, 9/9 × 3)에서 상판 3개(7~9번)만 x+ 쪽으로 밀려 놓였다(3~6 mm, 자로 잼). 상판만 손목을 90° 돌려 놓는 블록이라, 그리퍼 · TCP 축이 맞는지 확인했다.

## 2. 방법
1. 블록 1개를 p1에 놓고, 조립 영역은 비운다.
2. p1에서 FLAT_LONG으로 집어 조립 원점에 놓는다(회전 없음).
3. 관측 자세(`observe`)에서 손목 카메라 사진 ①.
4. 그 블록을 다시 집어 같은 자리에서 손목만 돌려 놓는다.
5. 같은 관측 자세에서 사진 ②. 두 사진의 블록 중심 차이 = 블록 이동.

- 속도 0.3, 펜던트 비상정지를 든 상태로 했다.

## 3. 결과

| 시각 | 회전 | 블록 이동 |
|---|---|---|
| 20:23 | 180° | 0.4 mm (긴 축 +0.3 · 직각 −0.3 mm, 잡은 폭 75.2 mm) |
| 21:11 | 90° | 2.2 mm |
| 21:14 | +90° | 3.3 mm |
| | −90° | 4.3 mm |
| | +90° | 4.1 mm |
| | −90° | 3.6 mm |

- 21:14는 블록을 원점에 둔 채 왕복 4번 했다.
- 방향(+/−) 부호는 측정 방식상 믿을 수 없어서 크기만 썼다.

## 4. 결론
**그리퍼 · TCP 축은 이상 없다.** 그리퍼 가운데가 TCP에서 비켜 있으면 180° 회전에서 가장 크게 보여야 하는데 0.4 mm였다(비켜남 약 0.1 mm).
