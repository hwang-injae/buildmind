## 문서 파일 이름 규칙 (팀 규칙 ⑨)

```
이름_v<버전>_<MMDDHH>.md
예: 03_설계_SDD_v3_100717.md   (v3, 10월 7일 17시)
```

- **🆕 10/13 23시 ~ 10/16 시연: 파일 이름(버전 · 월일시)을 바꾸지 않는다 — 내용만 고친다**(10/13 PL, 결정 기록 E-109). `docver.py touch` · `major`를 쓰지 않고, 새 문서만 만들 때 월일시를 붙인다. 이름 정리는 시연 뒤 PM이 한 번에. 아래는 그 밖 기간의 규칙이다.
- **버전은 크게 바뀔 때만** 올린다. 작은 수정은 월일시만 새로 쓴다.
- **이전 판은 git 이력**에 있다. 새 판이 나오면 옛 판은 지운다(10/4 PL 결정).
- 이름은 도구로 바꾼다. 저장소 맨 위 `README.md`와 `docs/` 안의 링크도 같이 고쳐진다.

  ```bash
  python3 tools/docver.py touch <파일>   # 작은 수정: 월일시만
  python3 tools/docver.py major <파일>   # 큰 변경: v1 -> v2
  ```

- 이 규칙에서 빼는 것: 폴더 안내 `README.md`, `.github/` 파일, 코드, 그림.
- 시험 기록은 `<ID>_<내용>_<이름>_v1_<MMDDHH>.md`, 트러블슈팅은 `TS-번호_짧은제목_v1_<MMDDHH>.md`.
