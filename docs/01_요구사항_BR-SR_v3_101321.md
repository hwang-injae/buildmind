## 1. 비즈니스 요구 (BR)

### 1.1 목적

이 프로젝트의 목적은 사업 성과가 아니다. 아래 기술을 실제 로봇에서 써 보고 확인하는 것이다.

1. **요청 → AI 설계:** 사람이 웹 글이나 말로 요청하면, AI(Claude — 10/13 E-99, 옛 GPT-4o)가 사람이 고른 설계를 바탕으로(같은 Template의 다른 설계 · 조립 결과는 참고 — E-72 → E-96) 부품마다 위치 · 방향 · 역할 · 그룹 · 순서 · 단계 · 잡기를 **직접 써** 젠가 설계도를 만든다(10/8 E-69 — 옛 '튜닝 → 자유 생성' 두 길은 없앰).
2. **검사 → 세대 관리:** 만든 설계를 규칙으로 검사하고(무너지지 않는지 · 로봇이 잡을 수 있는지 · 닿는지), 통과한 설계를 DB에 **부모 → 자식 버전**으로 쌓는다. 조립 결과도 함께 기록해 다음 생성에 쓴다(RAG).
3. **설계도 → 로봇 조립:** 기본 설계든 생성 설계든 같은 레시피 파일(`_recipe.json` 구조 + `_placements.csv` 조립 방법, 10/8 E-69)로 바꿔 MoveIt2(ROS 2용 로봇팔 동작 계획 소프트웨어)로 집고 놓는다. 이 프로젝트의 핵심 로봇 기술이다.
4. **실물 → 설계도 → 복제:** 사람이 완성한 젠가 구조물을 손목 깊이 카메라로 스캔해 블록 단위 설계도로 만들고, 로봇이 똑같이 조립한다(물리 → 디지털 → 물리).
5. 사람과 번갈아 쌓는 **협동 동작은 챌린지**로 미룬다(E-03). 학습형 VLA(보고 · 듣고 · 움직이는 학습 모델)는 하지 않는다.

### 1.2 배경과 문제

- 실제 산업에는 설계 데이터대로 재료를 쌓고 조립하는 로봇이 있다(벽돌 쌓기 로봇, 목조 부재 조립 로봇). 연구에서는 글로 설명한 구조물을 무너지지 않게 설계해 로봇이 조립하는 시도가 있다. 예: CMU [BrickGPT](https://github.com/AvaLovelace1/BrickGPT)(ICCV 2025 최우수 논문) — 맞물리는 블록, 학습한 모델, 양팔 로봇.
- 10/3 주제("CAD 설계도대로 쌓는 협동로봇")는 **정해진 설계도를 그대로 쌓는 로봇**이라 Pick & Place에 그칠 수 있다는 피드백을 받았다(10/6).
- 우리는 **설계도를 AI가 만들고 관리하는 쪽**으로 바꾼다. 맞물림 없는 젠가 블록, 팔 하나, GPU 없이(설계 AI Claude는 웹 PC 호스트 중계 — E-99), 학습 없이(규칙 검사 + 프롬프트) 책상 크기에서 한다. 선행 프로젝트와 다른 점: 설계 생성 · 검사 · 세대 관리 · 조립 · 실물 스캔 복제를 한 흐름으로 잇는다.

**문제 정의(E-02):** "웹 글이나 말로 요청하면 AI가 기본 설계(책상 · 의자)를 튜닝 · 생성해 새 젠가 설계도를 만들고, 검사 · 저장한 뒤 로봇이 조립한다. 사람이 완성한 구조를 스캔하면 설계도로 만들어 똑같이 조립한다." (→ 10/8 E-69: '튜닝 · 생성' 두 길 → AI가 DB 예시를 보고 설계도를 직접 쓴다)

## 5. 안전 요구 (SR)

정지는 이 프로젝트에서 가장 먼저 확인할 기능이다. 10/3 가상 시험에서 MoveIt 실행 취소와 두산 `move_stop`만으로는 팔이 서지 않았고, '서기 궤적'(지금 자리에 서라는 0.3초짜리 궤적)만 팔을 세웠다(R-01). **10/4(W010) 박진용이 Ctrl+C 즉시 정지를 넣고 실기에서 확인했다.** 10/6 박진용: 서기 궤적은 액션이 아니라 **토픽 `/dsr_moveit_controller/joint_trajectory`** 로 보내야 실기에서 섰다. 남은 R-02 재시험(정지 → 다시 시작, 보호 정지 해제, 충돌 감지)은 10/7 오전 정지 실기(W059)로 잡았고, W059는 완료됐다(Ctrl+C · 펜던트 비상정지 즉시 정지, PR #29 — 항목별 결과는 04 결과표). 화면 [정지] 실기는 화면 · 다리가 생긴 뒤 한다. 문제와 해결 과정은 [TS-01](troubleshooting/TS-01_정지가_안_들음_R-01_v1_100916.md)에 있다.

**웹캠을 쓰지 않으므로**(E-19) 사람 감지 → 정지는 없다. 사람은 로봇이 움직일 때 작업 영역 밖에 있고, 그것을 **출발 · 스캔 버튼을 누르는 사람이 확인**한다(SR-07). 안전 장치는 펜던트 비상정지 · 화면 정지 버튼 · Ctrl+C · 로봇 알람 · 두산 충돌 감지 · 저속이다(로봇 PC 키 정지는 안 씀 — 10/14 PL).
