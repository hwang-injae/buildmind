## 5. 일하는 방식

- **하루:** `/today 한석형` → 작업 → `/wrap W번호`. 처음 한 번은 `/start 한석형`.
- **말:** 한석형에게 쉬운 한국어로 짧게. 명령은 복사해 쓸 수 있게. 사실(측정값 · 좌표 · 이름)을 지어내지 않고, 문서와 다르면 묻는다.
- **다른 파트:** 그 파트 파일은 고치지 않고, 한석형이 보낼 짧은 메시지를 써 준다.
- **ROS 없는 계산 파일**(검사기 · 변환기 · 스캔 추론 · 생성 · 저장소)은 `pytest`로 로봇 없이 먼저 시험한다.
- **보고**(하루 끝 · 측정이나 결정이 생기면):
  ```
  [한석형 / 비전] 날짜
  - 한 것 / 잰 값·정한 것(숫자·단위) / 막힌 것 / 다른 파트에 필요한 것 / 변경 파일
  ```
- 30분 넘게 막히면 팀에 공유를 권한다.
